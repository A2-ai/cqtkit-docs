## Description

Generates PK parameters Cmax and Tmax for exposure predictions.






## Usage

```r
compute_pk_parameters(
  data,
  id_col,
  dose_col,
  conc_col,
  ntime_col,
  group_col = NULL
)
```

## Value

A tibble with PK summary statistics by factor `group`: N, Tmax
(median/min/max), and Cmax (geometric mean, CV%, median/min/max)



## Examples

```r
compute_pk_parameters(
  preprocess(cqtkit_data_verapamil) |> dplyr::filter(DOSE != 0),
  ID,
  DOSE,
  CONC,
  NTLD)
```
