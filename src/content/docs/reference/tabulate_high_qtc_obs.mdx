## Description

Tabulates number of high QTc/deltaQTc observations.






## Usage

```r
tabulate_high_qtc_obs(
  data,
  qtc_col,
  deltaqtc_col,
  group_col = NULL,
  group_label = NULL,
  qtc_label = "QTc",
  unit = "ms",
  qtc_thresholds = c(450, 480, 500),
  dqtc_thresholds = c(30, 60),
  title = NULL,
  ...
)
```

## Value

A gt table with counts of observations exceeding each threshold



## Examples

```r
tabulate_high_qtc_obs(
  cqtkit_data_verapamil, QTCF, deltaQTCF, group_col = DOSEF, qtc_label = "QTcF"
)
tabulate_high_qtc_obs(cqtkit_data_verapamil, QTCF, deltaQTCF, qtc_thresholds = c(430, 450))
```
