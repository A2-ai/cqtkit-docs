## Description

Compute Delta HR Baseline Mean

## Usage

```r
compute_delta_hrblm(data, id_col = ID, hrbl_col = HRBL, deduplicate = TRUE)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `data` | A data frame containing C-QT analysis dataset |
| `id_col` | An unquoted column name for subject ID |
| `hrbl_col` | An unquoted column name for baseline HR measurements, default is HRBL |
| `deduplicate` | Logical, whether to remove duplicate baseline values before averaging |

## Value

A data frame with deltaHRBL column added

## Examples

```r
compute_delta_hrblm(cqtkit_data_verapamil)
```
