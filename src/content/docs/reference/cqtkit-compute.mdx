## Description

These functions return tibbles of various computations done for C-QT analyses.







## compute

- [`compute_grouped_mean_sd`](../compute_grouped_mean_sd/) - This function computes averaged dependent variable grouped by time.
- [`compute_pk_parameters`](../compute_pk_parameters/) - This function computes pharmacokinetic parameters.
- [`compute_ecg_param_summary`](../compute_ecg_param_summary/) - This function computes summary stastics of ECG parameters.
- [`compute_high_qtc_subjects`](../compute_high_qtc_subjects/) - This function computes the number of subjects with at least one high QTc observation.
- [`compute_high_qtc_observations`](../compute_high_qtc_observations/) - This function computes the number of observations with high QTc values.
- [`compute_high_qtc_sub`](../compute_high_qtc_sub/) - Deprecated, use `compute_high_qtc_subjects()`.
- [`compute_quantiles_obs_df`](../compute_quantiles_obs_df/) - This function computes the average dependent variable within bins of independent variable.
- [`compute_potential_hysteresis`](../compute_potential_hysteresis/) - This function computes if hysteresis is detected within a dose group.
- [`compute_hysteresis_labeller`](../compute_hysteresis_labeller/) - This function computes a labeller function to show potential hysteresis results in facet labels.
- [`compute_contrast_observations`](../compute_contrast_observations/) - This funcction computes observations of a dependent variable optionally, contrasted with a control group
- [`compute_exposure_predictions`](../compute_exposure_predictions/) - This function computes predicted effect at drug exposure of interest.
- [`compute_dataset_simulation`](../compute_dataset_simulation/) - This function computes a simulation of dataset with fitted model.
- [`compute_summary_statistics_of_simulations`](../compute_summary_statistics_of_simulations/) - This function computes the summary statistics of a simulated dataset.
- [`compute_lm_fit_df`](../compute_lm_fit_df/) - This function computes extracts the fitted parameters from a linear regression model.
- [`compute_enGRI`](../compute_engri/) - This function computes the enGRI score for detecting hysteresis.
