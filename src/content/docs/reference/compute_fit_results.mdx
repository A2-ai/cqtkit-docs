## Description

Computes all fitted results and residuals for GOF plots.






## Usage

```r
compute_fit_results(data, fit, dv_col, conc_col, ntime_col, trt_col = NULL)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>data</code></td>
<td>A data frame containing C-QT analysis dataset</td>
</tr>
<tr>
<td><code>fit</code></td>
<td>An nlme::lme model object from model fitting</td>
</tr>
<tr>
<td><code>dv_col</code></td>
<td>An unquoted column name for observed model dependent variable</td>
</tr>
<tr>
<td><code>conc_col</code></td>
<td>An unquoted column name for observed Concentration measurements</td>
</tr>
<tr>
<td><code>ntime_col</code></td>
<td>An unquoted column name for time points for measurements</td>
</tr>
<tr>
<td><code>trt_col</code></td>
<td>An unquoted column name for treatment group, default NULL</td>
</tr>
</tbody>
</table>
</div>


## Value

A tibble with observed DV, concentration, time, population/individual predictions (PRED/IPRED), residuals (RES/IRES/WRES/IWRES), and the remaining columns of `data`



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

fit <- fit_prespecified_model(
  data_proc,
  deltaQTCF,
  ID,
  CONC,
  deltaQTCFBL,
  TRTG,
  TAFD,
  "REML",
  TRUE
)

compute_fit_results(data_proc, fit, deltaQTCF, CONC, NTLD, TRTG)
```
