## Description

These functions customize the style of plots







## style

- [`add_horizontal_references`](../add_horizontal_references/) - Adds dashed horizontal reference lines to plots. Deprecated in 1.2.1. Use the `reference_threshold` argument
- [`style_spec`](https://rdrr.io/pkg/ggstylekit/man/style_spec.html)<span style = {{ display: 'inline-block', verticalAlign: 'middle' }}><Icon name="external" /></span>, [`legend_spec`](https://rdrr.io/pkg/ggstylekit/man/legend_spec.html)<span style = {{ display: 'inline-block', verticalAlign: 'middle' }}><Icon name="external" /></span>, [`reveal`](https://rdrr.io/pkg/ggstylekit/man/reveal.html)<span style = {{ display: 'inline-block', verticalAlign: 'middle' }}><Icon name="external" /></span>, [`restyle_plot`](https://rdrr.io/pkg/ggstylekit/man/restyle_plot.html)<span style = {{ display: 'inline-block', verticalAlign: 'middle' }}><Icon name="external" /></span> - Re-exported from **ggstylekit** so plots can be styled without attaching it
- [`set_style`](../set_style/), [`style_plot`](../style_plot/) - Deprecated in 1.2.0. Use `style_spec()` and `restyle_plot()`
