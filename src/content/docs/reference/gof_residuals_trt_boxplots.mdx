## Description

Generates boxplots of residuals for treatment group.






## Usage

```r
gof_residuals_trt_boxplots(
  data,
  fit,
  dv_col,
  conc_col,
  ntime_col,
  trt_col = NULL,
  residual_references = c(-2, 2),
  legend_location = lifecycle::deprecated(),
  style = list()
)
```

## Value

A 2-panel boxplot of WRES and IWRES residuals by treatment group



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)
fit <- fit_prespecified_model(
  data_proc,
  deltaQTCF,
  ID,
  CONC,
  deltaQTCFBL,
  TRTG,
  TAFD,
  "REML",
  TRUE
)
gof_residuals_trt_boxplots(data_proc, fit, deltaQTCF, CONC, NTLD, TRTG)
```
