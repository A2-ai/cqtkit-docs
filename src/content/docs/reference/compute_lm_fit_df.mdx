## Description

Fits a linear model of input data frame.






## Usage

```r
compute_lm_fit_df(data, xdata_col, ydata_col, conf_int = 0.95)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>data</code></td>
<td>A data frame containing C-QT analysis dataset</td>
</tr>
<tr>
<td><code>xdata_col</code></td>
<td>An unquoted column name for independent variable measurements</td>
</tr>
<tr>
<td><code>ydata_col</code></td>
<td>An unquoted column name for dependent variable measurements</td>
</tr>
<tr>
<td><code>conf_int</code></td>
<td>Numeric confidence interval level (default: 0.9)</td>
</tr>
</tbody>
</table>
</div>


## Value

A tibble with linear model coefficients (intercept, slope), their confidence intervals, and p-values



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

compute_lm_fit_df(data_proc, RR, QT)
```
