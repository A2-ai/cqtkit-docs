## Description

Converts pk_parameters df into gt table for printing.






## Usage

```r
tabulate_pk_parameters(
  data,
  id_col,
  dose_col,
  conc_col,
  ntime_col,
  group_col = NULL,
  decimals = 2,
  title = NULL,
  ...
)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>data</code></td>
<td>A data frame containing C-QT analysis dataset</td>
</tr>
<tr>
<td><code>id_col</code></td>
<td>An unquoted column name for subject ID</td>
</tr>
<tr>
<td><code>dose_col</code></td>
<td>An unquoted column name for dose measurements</td>
</tr>
<tr>
<td><code>conc_col</code></td>
<td>An unquoted column name for drug concentration measurements</td>
</tr>
<tr>
<td><code>ntime_col</code></td>
<td>An unquoted column name for nominal time since dose</td>
</tr>
<tr>
<td><code>group_col</code></td>
<td>An unquoted column name for additional grouping column</td>
</tr>
<tr>
<td><code>decimals</code></td>
<td>Number of decimals to format the table to (default: 2, format for N is 0 decimals)</td>
</tr>
<tr>
<td><code>title</code></td>
<td>Optional title for the table, it will be wrapped in gt::md()</td>
</tr>
<tr>
<td><code>...</code></td>
<td>Optional additional arguments to gt::tab_options</td>
</tr>
</tbody>
</table>
</div>


## Value

A gt table with PK parameters: N, Tmax (median/min/max), Cmax (geometric mean, CV%, median/min/max) by dose group



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

tabulate_pk_parameters(data_proc |> dplyr::filter(DOSE != 0), ID, DOSE, CONC, NTLD)
```
