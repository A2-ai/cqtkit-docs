## Description

Plots scatter plot with linear and loess regressions. Can be used to check for linearity.






## Usage

```r
eda_scatter_with_regressions(
  data,
  ydata_col,
  xdata_col,
  trt_col = NULL,
  reference_threshold = NULL,
  loess_line = TRUE,
  linear_line = TRUE,
  span = 0.99,
  conf_int = 0.9,
  style = list()
)
```

## Value

A scatter plot with linear and/or LOESS regression lines for assessing linearity



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

eda_scatter_with_regressions(
  data_proc,
  deltaQTCF,
  CONC,
  TRTG,
  reference_threshold = 10)
```
