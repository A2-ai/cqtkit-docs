## Description

Compute Delta QTcB Baseline Mean

## Usage

```r
compute_delta_qtcbblm(
  data,
  id_col = ID,
  qtcbbl_col = QTCBBL,
  deduplicate = TRUE
)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `data` | A data frame containing C-QT analysis dataset |
| `id_col` | An unquoted column name for subject ID |
| `qtcbbl_col` | An unquoted column name for baseline QTCB measurements, default is QTCBBL |
| `deduplicate` | Logical, whether to remove duplicate baseline values before averaging |

## Value

A data frame with deltaQTCBBL column added

## Examples

```r
compute_delta_qtcbblm(compute_qtcb_qtcf(cqtkit_data_verapamil))
```
