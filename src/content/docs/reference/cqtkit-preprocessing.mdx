## Description

Overview of data preprocessing function in **cqtkit**







## preprocessing

- [`compute_hr`](../compute_hr/) - This function derives HR and baseline HR from RR intervals
- [`compute_qtcb_qtcf`](../compute_qtcb_qtcf/) - This function computes Bazette’s and Fridericia’s QT correction
- [`compute_blm`](../compute_blm/) - This function adds a population mean baseline value for an ECG parameter from a baseline dataset
- [`compute_delta_qtcbblm`](../compute_delta_qtcbblm/) - This function computes difference between QTcB and mean baseline QTcB
- [`compute_delta_qtcfblm`](../compute_delta_qtcfblm/) - This function computes difference between QTcF and mean baseline QTcF
- [`compute_delta_hrblm`](../compute_delta_hrblm/) - This function computes difference between HR and mean baseline HR
- [`compute_deltas`](../compute_deltas/) - This function computes delta ECG parameters between baseline and on treatment
- [`preprocess`](../preprocess/) - This is a wrapper function to compute all QT corrections, delta ECG, and delta Baseline Mean values
