## Description

Returns quantiles of concentrations and deltaQTc values.






## Usage

```r
compute_quantiles_obs_df(
  data,
  xdata_col,
  ydata_col,
  conf_int = 0.9,
  nbins = 10,
  type = 2
)
```

<td>An unquoted column name for deltaQTc measurements</td>

<tr>

<td>Numeric confidence interval level (default: 0.9)</td>
</tr>
<tr>

<td>Integer number of bins to break independent variable into - OR - a user specified vector for non-uniform binning</td>
</tr>
<tr>
<td><code>type</code></td>
<td>Algorithm for quantile. Default (2), is SAS quantile algorithm</td>
</tr>

</table>
</div>


## Value

A tibble with binned concentration medians and corresponding deltaQTc statistics (mean, SD, SE, CI, median, quantiles)



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

compute_quantiles_obs_df(data_proc, CONC, deltaQTCF)
```
