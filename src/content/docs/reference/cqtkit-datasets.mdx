## Description

cqtkit has datasets from four different drugs included in the packge. These data was originally made available in the following publication and obtained from Physionet.
Each drug has been filtered into its own dataset and is ready to use with cqtkit.







## datasets

- [`cqtkit_data_verapamil`](../cqtkit_data_verapamil/) - dataset for Verapamil (minimal QTc prolongation)
- [`cqtkit_data_bl_verapamil`](../cqtkit_data_bl_verapamil/) - baseline data for Verapamil
- [`cqtkit_data_dofetilide`](../cqtkit_data_dofetilide/) - dataset for Dofetilide (significant QTc prolongation)
- [`cqtkit_data_bl_dofetilide`](../cqtkit_data_bl_dofetilide/) - baseline data for Dofetilide
- [`cqtkit_data_quinidine`](../cqtkit_data_quinidine/) - dataset for Quinidine (significant QTc prolongation)
- [`cqtkit_data_bl_quinidine`](../cqtkit_data_bl_quinidine/) - baseline data for Quinidine
- [`cqtkit_data_ranolazine`](../cqtkit_data_ranolazine/) - dataset for Ranolazine (moderate QTc prolongation)
- [`cqtkit_data_bl_ranolazine`](../cqtkit_data_bl_ranolazine/) - baseline data for Ranolazine
