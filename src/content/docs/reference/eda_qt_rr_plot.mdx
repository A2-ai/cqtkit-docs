## Description

Plots QT against RR.






## Usage

```r
eda_qt_rr_plot(
  data,
  rr_col,
  qt_col,
  id_col = NULL,
  trt_col = NULL,
  conf_int = 0.9,
  model_type = c("lm", "lme"),
  show_model_results = TRUE,
  method = "REML",
  remove_rr_iiv = FALSE,
  style = list(),
  include_pvalue = FALSE,
  pvalue_eps = NULL,
  decimals = NULL,
  scientific = TRUE
)
```

## Value

A scatter plot of QT vs RR with optional regression line and slope estimate caption



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

eda_qt_rr_plot(data_proc, RR, QT, ID, model_type = "lme")
```
