## Description

Computes the number of observations (rows) where QTc exceeds specified
thresholds or deltaQTc exceeds specified thresholds.






## Usage

```r
compute_high_qtc_obs(
  data,
  qtc_col,
  deltaqtc_col,
  group_col = NULL,
  qtc_thresholds = c(450, 480, 500),
  dqtc_thresholds = c(30, 60)
)
```

## Value

A tibble with counts of observations exceeding each threshold



## Examples

```r
compute_high_qtc_obs(cqtkit_data_verapamil, QTCF, deltaQTCF)
compute_high_qtc_obs(cqtkit_data_verapamil, QTCF, deltaQTCF, qtc_thresholds = c(430, 450))
```
