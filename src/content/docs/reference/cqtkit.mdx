## `cqtkit` Functions

`cqtkit` has seven main classes of functions for analyzing C-QT data:

<Steps>
1. [Preprocessing](../preprocessing/) - these functions compute QT corrections and baseline means
2. [EDA](../eda/) - these functions generate exploratory data analysis plots
3. [Compute](../compute/) - these functions compute various aspects of QT analyses
4. [Tabulate](../tabulate/) - these functions generate summary and analysis tables 
5. [Fit](../fit/) - These functions generate the prespecified linear mixed effects model
6. [GoF](../gof/) - these functions generate goodness-of-fit plots of a fitted model
6. [Predict](../predict/) - these functions generate prediction plots
</Steps>

`cqtkit` also has plot manipulation functions:
<Steps>
1. [Style](../style/) - these functions style a ggplot object
</Steps>

`cqtkit` also has included datasets:
<Steps>
1. [Datasets](../datasets/) - a baseline and on-treatment dataset ready for use with `cqtkit`
</Steps>
