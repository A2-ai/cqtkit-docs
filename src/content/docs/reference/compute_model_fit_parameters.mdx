## Description

Converts tTable of summary(model_fit) to tibble and adds CIs.






## Usage

```r
compute_model_fit_parameters(
  fit,
  trt_col_name = "TRTG",
  tafd_col_name = "TAFD",
  id_col_name = "ID",
  conf_int = 0.95,
  conc_col_name = "CONC",
  baseline_col_name = "deltaQTCFBL",
  include_reference_levels = FALSE,
  section = FALSE
)
```

## Value

A tibble with fixed effect estimates, standard errors, degrees of freedom, t-values, p-values, confidence intervals, and random effect variances



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

fit <- fit_prespecified_model(
  data_proc,
  deltaQTCF,
  ID,
  CONC,
  deltaQTCFBL,
  TRTG,
  TAFD,
  "REML",
  TRUE
)
compute_model_fit_parameters(fit)
```
