## Description

[![[Deprecated]](/figures/lifecycle-deprecated.svg)](https://lifecycle.r-lib.org/articles/stages.html#deprecated)

## Details

Despite its name, this function counts observations, not subjects. Use
[`compute_high_qtc_subjects()`](../compute_high_qtc_subjects/) for subject counts or
[`compute_high_qtc_observations()`](../compute_high_qtc_observations/) for observation counts.






## Usage

```r
compute_high_qtc_sub(data, qtc_col, deltaqtc_col, group_col = NULL)
```

## Value

A tibble with counts of observations exceeding QTc thresholds (450, 480, 500 ms) and deltaQTc thresholds (30, 60 ms)




## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)

compute_high_qtc_sub(data_proc, QTCF, deltaQTCF)
```
