## Description

Adds an `HR` column to `data` computed as `60000 / RR` (ms -> bpm), and
optionally an `HRBL` column computed from a baseline RR column.

## Details

Intended for ECG data that has not yet been averaged across replicates.
On replicate-averaged data the result is `60000` divided by a mean RR,
which is not the mean of the replicate heart rates.






## Usage

```r
compute_hr(data, rr_col = RR, rrbl_col = RRBL)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>data</code></td>
<td>A data frame containing an RR column.</td>
</tr>
<tr>
<td><code>rr_col</code></td>
<td>Unquoted column name for RR measurements. Default `RR`. Pass `NULL` to skip the HR computation.</td>
</tr>
<tr>
<td><code>rrbl_col</code></td>
<td>Unquoted column name for baseline RR measurements. Default `RRBL`. Pass `NULL` to skip the HRBL computation.</td>
</tr>
</tbody>
</table>
</div>


## Value

`data` with `HR` and/or `HRBL` columns added. Existing columns
of those names are left unchanged.




## Examples

```r
compute_hr(
  dplyr::select(cqtkit_data_bl_verapamil, -HR),
  rrbl_col = NULL
)
```
