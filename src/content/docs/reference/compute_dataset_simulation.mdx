## Description

Simulates a dataset used to fit the model.






## Usage

```r
compute_dataset_simulation(data, fit, xdata_col, sim_num = 0)
```

## Arguments

<div class="arg-table">
<table>
<thead>
<tr><th>Argument</th><th>Description</th></tr>
</thead>
<tbody>
<tr>
<td><code>data</code></td>
<td>A data frame containing C-QT analysis dataset</td>
</tr>
<tr>
<td><code>fit</code></td>
<td>An nlme::lme model object from model fitting</td>
</tr>
<tr>
<td><code>xdata_col</code></td>
<td>An unquoted column name for xdata</td>
</tr>
<tr>
<td><code>sim_num</code></td>
<td>An optional simulation number</td>
</tr>
</tbody>
</table>
</div>


## Value

A tibble with simulated predictions (pred), concentration values (xdata), and simulation number



## Examples

```r
data_proc <- preprocess(cqtkit_data_verapamil)
fit <- nlme::lme(
  fixed = deltaQTCF ~ 1 + CONC,
  random = ~ 1 | ID,
  data = data_proc
)

compute_dataset_simulation(data_proc, fit, CONC)
```
