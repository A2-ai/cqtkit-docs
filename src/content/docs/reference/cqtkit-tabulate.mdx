## Description

These functions generate gt tables of various analyses.







## tabulate

- [`tabulate_study_summary`](../tabulate_study_summary/) - This function generates a table of the C-QT study status.
- [`tabulate_ecg_param_summary`](../tabulate_ecg_param_summary/) - This function generates central tendency tables for a ECG parameter (QTc, HR).
- [`tabulate_high_qtc_subjects`](../tabulate_high_qtc_subjects/) - This function generates a table of the number of subjects with at least one high QTc observation.
- [`tabulate_high_qtc_observations`](../tabulate_high_qtc_observations/) - This function generates a table of the number of observations with high QTc values.
- [`tabulate_high_qtc_sub`](../tabulate_high_qtc_sub/) - Deprecated, use `tabulate_high_qtc_subjects()`.
- [`tabulate_pk_parameters`](../tabulate_pk_parameters/) - This function generates a table of Pharmacokinetic parameters ($C_max$, $T_max$)
- [`tabulate_model_fit_parameters`](../tabulate_model_fit_parameters/) - This function generates a table of estimated fixed effect parameters with confidence intervals.
- [`tabulate_exposure_predictions`](../tabulate_exposure_predictions/) - This function generates a table of predicted dependent variable ($(\Delta) \Delta $QTc, $(\Delta) \Delta$HR) at drug exposure levels of interest.
