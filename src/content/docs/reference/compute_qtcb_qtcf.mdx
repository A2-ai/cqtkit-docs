## Description

Compute QTcB QTcF






## Usage

```r
compute_qtcb_qtcf(
  data,
  qt_col = QT,
  qtbl_col = QTBL,
  rr_col = RR,
  rrbl_col = RRBL
)
```

<table>

<tbody>
<tr>
<td><code>data</code></td>
<td>A data frame containing QT, RR, QTBL, RRBL</td>
</tr>
<tr>
<td><code>qt_col</code></td>

<tr>

<td>An unquoted column name for baseline QT measurements</td>
</tr>
<tr>
<td><code>rr_col</code></td>
<td>An unquoted column name for RR measurements</td>
</tr>
<tr>
<td><code>rrbl_col</code></td>
<td>An unquoted column name for baseline RR measurements</td>
</tr>
</tbody>
</table>
</div>


## Value

A data frame with QTCF, QTCB, QTCFBL, and QTCBBL columns added



## Examples

```r
compute_qtcb_qtcf(
  dplyr::select(cqtkit_data_bl_verapamil, -QTCB, -QTCF),
  qtbl_col = NULL,
  rrbl_col = NULL
)
```
