## Description

Computes the exposure-normalized Glomb-Ring Index (enGRI).

## Usage

```r
compute_enGRI(data, conc_gm_col, ddqtc_col)
```

## Arguments

| Argument | Description |
|----------|-------------|
| `data` | A data frame containing C-QT analysis dataset |
| `conc_gm_col` | CONC geometric mean column name |
| `ddqtc_col` | Delta delta QTc column name |

## Value

Numeric exposure-normalized Glomb-Ring Index value in ms, indicating hysteresis magnitude

## Examples

```r
compute_enGRI(preprocess(cqtkit_data_verapamil), CONC, deltaQTCF)
```
